# RCA-050: OVN-FAN-VIB: Recirculation fan high vibration

**Machine:** PNT-OV-02 (Cure Oven 2, Duerr Convection cure oven) - Area: Paint Shop
**Date:** 2026-07-14  **Shift:** B  **Downtime:** 296 min  **Estimated lost vehicles:** 146.1
**Work order:** WO-2026-005484  **Escalation level reached:** L6

## Problem statement
Operator reports: recirculation fan high vibration. Machine halted in cycle, alarm OVN-FAN-VIB.

## Containment
Line lead isolated the machine and rerouted material where possible. Maintenance supervisor was informed per the escalation matrix; vendor Duerr was engaged.

## Investigation
Arrived 15:49. Vibration analysis done: measurement; clean impeller. Measured vibration_mm_s = 5.40 mm/s (nominal 2.0, warn 5.0, alarm 8.0). Cause: fan imbalance from deposits.

## Root cause
Fan imbalance from deposits (category: Process drift).

## Corrective actions taken
Vibration analysis done: measurement; clean impeller.

## Preventive actions
- Review PM interval for related tasks and add checklist step for early detection.
- Evaluate condition-monitoring sensor (temperature) alert threshold for earlier warning.
- Verify spare parts stock for the affected component.
